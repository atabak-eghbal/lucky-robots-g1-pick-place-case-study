What was built

The starting point was a manual keyboard-controlled MuJoCo demo for the Unitree G1 humanoid. The submission converts that demo into an autonomous pick-and-place controller using an explicit 12-state finite-state machine, a kinematic grasp backend, and shared locomotion and manipulation ONNX policies.

The primary deliverable is the ground-truth FSM baseline (Steps 1–10). It is intentionally scoped as a debuggable baseline, not a production stack. Every threshold and timeout is backed by a log observation. A Visual Oracle perception extension is designed at the architectural level; its implementation status is described on the Visual Oracle page.

The end-to-end sequence completed in simulation: the robot settled, approached the source table, hovered and descended to the cylinder, attached it kinematically, lifted and transported it, lowered it above the target surface, and released it. Placement was visually successful in simulation; post-release settling validation has a known caveat described in Results.

Architecture at a glance

The runtime separates orchestration, policy logic, controller synthesis, grasp handling, and validation scripts so each layer can be instrumented and tested in isolation.

Key evidence from development logs

  • Headless smoke test passed: scene, cameras, bodies, sites, joints, and ONNX policy warmups all verified.
  • Walker double-normalization bug identified and fixed: raw observations must be passed directly to the walker ONNX policy.
  • Always-on reacher requirement: the right reacher must run unconditionally to keep arm joints inside the training distribution.
  • Empirical reacher accuracy floor: radial error plateaued around 12–13 cm; thresholds and timeouts were set around this floor.
  • Kinematic attach distance: 0.128 m measured in the reference run (snap_offset 0.030 m).
  • Target-side false-positive validation bug: reach-window checks alone produced false positives; world proximity and yaw gating were added.
