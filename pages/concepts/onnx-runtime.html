ONNX Runtime

ONNX Runtime runs the pre-trained walker and reacher neural-network policies.

What it means

  • ONNX is a portable model format.
  • ONNX Runtime executes exported models on CPU or GPU.
  • This repo treats walker.onnx and right_reacher.onnx as black-box policies.

Why it matters

The runtime wrapper makes policy inference a simple function call, which keeps the control loop predictable. That predictability is required to keep the walker and reacher stable under tight timing constraints.

How it appears in this repo

  • walker.onnx and right_reacher.onnx are loaded as pre-trained policies.
  • The wrapper uses CPUExecutionProvider for portability.
  • Policy outputs must match joint ordering and action scaling.

Design implications

  • Observation layout and scaling must stay consistent with training.
  • Latency matters because inference runs every control tick.
  • The models are treated as opaque—debugging relies on input/output logging.

Common failure modes or misunderstandings

  • Wrong input shape.
  • Wrong normalization.
  • Wrong joint order.
  • Action scaling mismatch.
