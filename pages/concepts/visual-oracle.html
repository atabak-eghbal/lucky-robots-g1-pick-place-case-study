Concept Notes

Visual Oracle

A Visual Oracle is a deterministic perception shortcut that estimates object position from simulated camera/depth information.

What it means

A Visual Oracle replaces ground-truth object lookup with camera-derived estimates. It is not a learned detector; it uses deterministic segmentation, depth, and geometry to estimate a pose.

Why it matters

The Oracle acts as a bridge between ground-truth control and learned perception. It lets the baseline exercise the perception/control interface without claiming production-ready sensing.

How it appears in this repo

  • Uses segmentation/depth/back-projection plus EMA smoothing.
  • Estimates are frozen during close-grasp phases to avoid occlusion jitter.
  • The Oracle feeds the FSM with a target pose for the source table.

Design implications

  • Useful for controlled experiments, not for real-world deployment.
  • Requires clear gating and freeze logic to avoid jitter during grasp.
  • Depends on simulator-specific segmentation and camera calibration.

Common failure modes or misunderstandings

  • Mistaking it for production perception.
  • Trusting estimates during occlusion.
  • Not freezing estimates during grasp.
  • Forgetting that segmentation may be simulation-specific.
