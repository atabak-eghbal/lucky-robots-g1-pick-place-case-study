Managing Complexity with States

The pick-and-place task is decomposed into 12 distinct states. This makes locomotion, perception, and grasping failures separable and traceable. 

SETTLE            → APPROACH_SOURCE  → HOVER_SOURCE
DESCEND_SOURCE    → CLOSE_GRIP       → LIFT_SOURCE
APPROACH_TARGET   → HOVER_TARGET     → LOWER_TARGET
OPEN_GRIP         → RETRACT          → DONE

Critical State Transitions

State Exit Condition Safety Risk Mitigated
APPROACH_TARGET Near waypoint + Yaw Aligned New: Prevents premature arm extension during turns.
OPEN_GRIP Wait 15 ticks after release Critical: Prevents NaN crashes from finger-object overlap.
LIFT_SOURCE Palm clearance > 25cm Ensures object has physically left the table before transport.
