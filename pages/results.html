The most recent physical-grasp experiments should not be reported as solved task completion. The correct result is that the robot now approaches the object and nearly lifts it using more physically honest contact/caging logic, but slip during lift remains unresolved. This is a useful engineering result because it isolates the remaining failure mode.

We also keep the evidence labels strict: "implemented," "validated by tests," and "physically successful in simulation" are reported separately, especially because prior grasp/release experiments exposed MuJoCo instability/NaN risks when contact transitions were mishandled (see Lessons → The Simulation Release NaN).

The Final Refinement

Breakthrough

Resolving the Release NaN

By delaying collision restoration by 15 physics ticks, we eliminated the NaN instability that occurred when kinematic release happened too close to the fingers. This moved placement from "visually verified" to "robustly verified."

Insight

Target Sweet-Spot

Offsetting the approach waypoint by +0.15m world-X ensured the robot faces the table head-on in its right arm's optimal reach zone, maximizing placement reliability.
